# Стрим-экраны KUBIK

Стрим-викторина находится в кабинете преподавателя внутри активного занятия, в блоке «Викторина занятия». Отдельный раздел «Викторины» не используется.

- «Экран викторины» открывает отдельное окно: ожидание, вопрос с общим таймером, рейтинг после вопроса и финальный топ-10.
- «Открыть лидерборд» на главном экране занятий показывает рейтинг за последние 7 дней по всем доступным предметам или одному выбранному.
- Для OBS используется захват отдельного окна «KUBIK — Трансляция». Управление остаётся в кабинете преподавателя.

## Викторина во время занятия

Для стрим-сценария используется режим «Один вопрос — управляет преподаватель». У каждого вопроса задаётся время от 5 до 300 секунд, по умолчанию 30 секунд.

После команды «Показать вопрос» backend фиксирует время старта. Когда время истекает, новые ответы больше не принимаются, а стрим-экран автоматически переключается на накопительный рейтинг. Следующий вопрос запускается преподавателем. Один правильный ответ даёт один балл; при равенстве баллов выше ученик с меньшим суммарным временем правильных ответов.

Правильные ответы, объяснения и ответы конкретных учеников не входят в stream API. Если викторина анонимная, на экране используются подписи «Участник 1», «Участник 2» и т. д.

## Рейтинг за 7 дней

В рейтинг входят лучшие результаты каждого домашнего задания за последние 168 часов и каждое уникальное правильно решённое задание практики. Повтор одного задания не увеличивает балл. Для практики используются баллы сложности: easy = 1, medium = 2, hard = 3.

Преподаватель видит только назначенные ему предметы. Администратор может открыть общий рейтинг. Экран обновляется раз в 30 секунд.

## Обновление базы

При старте backend существующий `sequelize.sync({ alter: true })` добавит:

- `lesson_quizzes.questionStartedAt`;
- `lesson_quiz_questions.timeLimit`;
- `lesson_quiz_answers.responseTimeMs`;
- `practice_question_results.lastCorrectAt`.
